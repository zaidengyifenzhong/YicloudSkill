# 指标与账单查询

## 何时读取

用户要求资源指标、用量、账单或费用明细时读取。这类请求只查询，不自动修改配额、停止资源或调整计费配置。

## 查询流程

1. 确定租户或项目范围、时间区间、时区与用户需要的维度。不能把租户总额当作项目费用。
2. 指标通过 monitor 服务，账单通过 bc 服务发现命令；已知操作直接 describe。
3. GetMonitorData 的 MetricName、StartTime、EndTime 和维度按实际 schema 填写，不套用训练日志的纳秒单位。
4. 账单根据用户范围选择总览、供给方式、项目、租户或明细查询；支持分页时读取完整需要的范围。
5. 核对返回的单位、币种、时间范围及聚合口径，再解释结果。

GetOverviewConsolidation 的总览截至前一日，月初可能查询上个月；按当前 describe 和实际返回周期核对。用户要求“本月”时，不能把上个月总览或未包含今日的数据说成完整本月费用。

## 判断与异常

空结果先核对时间、权限和维度，不当作零用量。查询失败报告错误，不能用估计值填补缺失账单。实时指标与月度结算可能口径不同，未有依据时不相减或推算最终费用。

## 完成标准

报告查询范围、日期、单位、实际数值和缺失项。需要采取节省资源的操作时，单独依据用户授权进入相应资源手册。
